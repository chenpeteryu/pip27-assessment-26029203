## 五、代码与接口约束

以下约束适用于用户后续授权开始作答时：

1. 保留 `problems/<题号>/` 的固定目录、命名和结构，不删除或重命名规定目录。
2. T0～T3 的官方接口头文件不得修改、删除、重命名，也不得通过新建同名头文件覆盖。类名、函数签名及类的对象布局须保持一致。
3. 可修改本题 `src/` 中已有 `.cpp`，可在本题 `src/` 新增辅助 `.cpp`，可在 `src/` 或 `include/` 新增不同名辅助 `.hpp`。
4. 辅助头文件须由参与编译的源码主动包含；头文件自身不单独编译。
5. T0～T3 不在 `src/` 中定义 `main()`；T4 为独立 ROS 2 节点，必须在 `src/` 中恰有一个 `main()`。T4 内部类、辅助头文件、回调和线程结构可自行设计。
6. T4 固定节点名 `/signal_estimator`、消息 `t4_realtime_estimation/msg/SignalPacket`（`std_msgs/Header header`、`float64[] values`）、Topic `/signal/observation`、`/signal/estimate`、`/signal/prediction`，以及参数服务 `/signal_estimator/set_parameters_atomically`、整数参数 `assessment_mode`（0～3）。不得修改通信协议。
7. 正式测评使用测评机的官方接口头文件与 CMake，编译本题 `src/` 下的源码；题目根目录的 `main.cpp` 与 `CMakeLists.txt` 仅用于本地调试，不参与正式测评。
8. 按文档要求学习并遵循 Google C++ Style Guide，并确保能够解释所提交实现的原理。
