# T1 第一版实现与验证记录

日期：2026-10-23。依据官方 v0.2.0 手册和模板，来源为算法/problems/T1_bipartite_matching/ 顶层 src。算法内容保持源文件原样，仅规范化 LF 换行。测试、实验、交接与构建材料留在算法工作区，不随本次作答导入；下述结果从原实现记录和本次复测整理。

## 算法

1. 无边返回长度为 L 的全 -1 数组。
2. 最大边权非正时，选择最大权单边，满足非空约束。
3. 存在正权时删除非正权边。删除它们不会降低最优权重，且正权边保证答案非空。
4. 建立容量均为 1 的 S→左部→右部→T 网络，匹配边费用为 -weight。
5. 利用初始分层结构在线性时间初始化可行势能；约化费用为 c+h[u]-h[v]。
6. 堆优化 Dijkstra 找最短增广路径，通过反向边撤销并调整已有匹配。
   到汇点即可提前结束；更新势能使用 min(dist[v],dist[T])，包括不可达节点，
   保证所有可用残量边的约化费用保持非负。
7. 路径原始费用非负时停止，提取流量为 1 的匹配边。

每次最短路增广保持当前流量下的最小费用；随着流量增加，最小费用的边际增量
非递减。因此第一次遇到非负增量即可停止，不会错过更高权重的匹配。
该论证基于残量网络与可行势能，不依赖逐边贪心。

内部费用、距离、势能统一使用 __int128，取负前先转换，避免 INT64_MIN
及交替路径中间值溢出。构造函数保存输入副本，求解使用局部状态，可重复调用。
最坏时间 O(K(E+L+R)log(L+R))，空间 O(E+L+R)，K≤min(L,R)。

## 第一版验证汇总

2026-10-23 重新构建并运行边界、15,000 组暴力对拍及重复调用，全部通过。Windows 使用测试专用 MSVC 128 位适配，编译出现 C4324 对齐填充警告；该适配未进入提交。提交代码仍使用 GCC 支持的 __int128。

四组本机大图耗时为 3592、6229、5198、3226 ms；历史 perf 中全正稠密图也出现临界或超时。大图只验证合法性，小图才有独立暴力最优值。并行构建与本机适配会影响计时，不能据此声称满足 Ubuntu 单核 3000 ms/512 MiB 限制。未运行官方隐藏测评。
