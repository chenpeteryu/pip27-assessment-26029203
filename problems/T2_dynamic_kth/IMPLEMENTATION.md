# T2 第一版实现与验证记录

日期：2026-10-23。依据官方 v0.2.0 手册和模板，来源为算法/problems/T2_dynamic_kth/ 顶层 src。算法内容保持源文件原样，仅规范化 LF 换行。测试、实验、交接与构建材料留在算法工作区，不随本次作答导入；下述结果从原实现记录和本次复测整理。

## 实现

- struct + vector 节点池，以整数下标连接，删除槽位可复用。
- mt19937_64 固定种子712367821，优先级相等时按槽位编号打破平局。
- 单调栈 O(N) 建树，并自底向上维护子树大小。
- 插入使用拆分、合并；删除拆出单节点并回收；修改按子树大小定位。
- 查询拆出闭区间，非递归中序收集后恢复树，再用 nth_element 找第 k 大。
- 官方 const 查询接口通过 Impl 修改临时内部结构，返回时序列与树结构恢复。
  同一对象不支持并发调用。
- 拆分、合并、收集均非递归，辅助栈存放在堆内存中。
- 在修改树连接前准备足够的工作空间，避免查询收集分配失败留下拆开的树。

建树 O(N)，插删改期望 O(log N)，查询期望/平均 O(log N+L)。
随机 Treap 不提供最坏高度保证；nth_element 也仅保证平均线性比较次数。
空间 O(Nmax)，工作区保留已用容量；节点池按历史最大活跃长度而非操作次数增长。
所有参数按题目有效输入保证处理，不额外定义非法参数行为。
