## 实现

- 连续块存储序列，Fenwick按块大小定位；块目标1024、最大2048、低于256时尝试合并。
- 普通增删在块内搬移，修改直接定位；短查询收集后以nth_element或MSD基数选择求排名。
- 重复精确全区间查询可以触发排序缓存。
- N>=8192、长度>=4096的查询，自上次修改后累计至少64次且累计扫描量>=32N，才构建当前序列的静态Wavelet Matrix快照。
- 快照通过当前值排序压缩，不预读未来操作；有效时长区间查询O(log N)。长度<4096仍走分块路径，防止预热后单点/短查询变慢。
- 每对象最多尝试构建一次，bad_alloc后回退。有效修改使快照失效，不在修改中重建索引。
- 保留固定官方PImpl接口，src没有main。同一对象不支持并发调用。

设m为块数、B为块大小、L为查询长度：普通增删O(log m+B)，update为O(log m)，块分裂/合并时另有O(m+B)单次成本。不命中快照的查询仍为O(log m+L+基数桶常数)。快照构建O(N log N)，索引空间O(N log N)，百万规模前缀计数约80MB。

## 明确保留的限制

1. 一次有效修改使已建快照永久失效；后续随机长查询回到O(L)。本地index_modify_random_long和phase_512仍在拓展1超时。
2. 失效索引仍占内存；百万规模测试进程峰值工作集约130MiB，含驱动，不等同虚拟地址空间。
3. 建索引存在一次性尖峰；短只读阶段可能净亏，固定门槛不是最坏耗时保证。
4. 未采用允许重建的v5/v6/v7：复核发现它们各有原v4能过而候选超过1秒的合法阶段负载。
5. 以上自建用例不等于官方测试点，不据此计算拓展得分或宣称考核通过。
